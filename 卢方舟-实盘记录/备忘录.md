## 一、日常追踪

### portfolio-review
分析当前持仓，给出调仓建议。每次必跑。
```
portfolio-review
或：portfolio-review @当前持仓文件路径
```

### news-pulse
股价异动时快速归因。不是深度投研，10-15分钟快速判断。
```
news-pulse 股票名称
例：news-pulse 华友钴业
```

### thesis-tracker
检查已买入股票的"投资论文"是否还成立。每季度跑一次。
```
thesis-tracker 股票名称
例：thesis-tracker 比亚迪
```

### thesis-drift
对比两份论文/报告快照，分清「事实变了」还是「只是措辞变了」。
```
thesis-drift 公司名
或：thesis-drift 公司名 旧报告路径 新报告路径
```

## 五、每次分析的要求

1. **取当前时间** → 用实时股价，不缓存
2. **先看 PE/ROE/毛利率** → 基础判断30秒
3. **看公司治理** → 实控人/关联交易/诚信记录
4. **给明确结论** → 可买/等待/回避，不说"可能"

### 额度省着用（Other Models 很贵）

| 场景 | 建议模型池 |
|------|------------|
| 日常持仓更新、问规则、news-pulse | Cursor Models（Grok/Composer） |
| research / checklist / earnings-review | 可用旗舰，但少开并行 |
| investment-team / earnings-team | 最贵；确认要烧额度再开 |
| 一次 portfolio-review（多 Agent） | 可吃掉约 30–40% Other Models |
